# 回归测试覆盖率统计报告

> 目的：度量回归测试对业务需求的覆盖程度，指导回归用例的补充与裁剪。
> 口径：本报告给出覆盖率**度量方法与计算口径**；覆盖率的实际数值须以真实回归执行结果计算后回填。

---

## 一、覆盖率度量方法

本系统采用**需求-用例-缺陷三层追溯**的覆盖度量：

```
需求项（业务功能点）
   └─ 关联测试用例（220条用例库，见 220条测试用例.csv）
        └─ 执行结果（通过/失败/未执行）
             └─ 失败项关联缺陷（见 04_缺陷管理/禅道缺陷台账.csv）
```

### 1. 用例级覆盖率（回归执行覆盖率）

```
用例执行覆盖率 = 已执行用例数（通过+失败） / 本回归范围用例总数 × 100%
```

### 2. 需求级覆盖率（功能点覆盖）

```
需求功能点覆盖率 = 已覆盖需求项数 / 需求项总数 × 100%
其中：某需求项只要被 >=1 条已执行用例覆盖即视为"已覆盖"
```

### 3. 本次报告推荐口径

单次回归以「用例执行覆盖率 + 需求功能点覆盖率」双口径统计；
达标线（如 95%）为项目约定目标，实际数值以真实执行为准。
