# Campus Bazaar 接口清单

> 来源：后端 controller 层真实接口定义（Spring Boot + MyBatis）
> 基地址：`http://localhost:8080`
> 认证：登录类接口基于 Session/Cookie；管理后台接口需管理员角色

---

## 一、用户模块 `/api/users`

| # | 方法 | 路径 | 认证 | 说明 | 参数 |
|---|------|------|------|------|------|
| 1 | POST | /api/users/register | 公开 | 注册 | body: username, password, nickname, phone, school, avatar |
| 2 | POST | /api/users/login | 公开 | 登录 | body: username, password |
| 3 | POST | /api/users/logout | 需登录 | 登出 | - |
| 4 | GET | /api/users/me | 需登录 | 当前用户信息 | - |
| 5 | PUT | /api/users/me | 需登录 | 修改个人信息 | body: nickname, avatar, phone, school |
| 6 | GET | /api/users/{id} | 公开 | 用户公开信息 | 路径: id |
| 7 | GET | /api/users/me/favorites | 需登录 | 我的收藏列表 | - |

## 八、字段口径速查

| 字段 | 取值 | 说明 |
|------|------|------|
| item.status | 0/1/2/3/4 | 待审核/在售/锁定/已售/下架 |
| order.status | 0/1/2/3 | 待确认/已确认/已完成/已取消 |
| user.role | 0/1 | 普通用户/管理员 |
| user.status | 0/1 | 禁用/正常 |
| condition_level | 1~5 | 几乎全新~大量使用痕迹 |
| score | 1~5 | 评价评分 |
| 响应格式 | {code, msg, data} | 统一 JSON 结构，code=0 表示成功 |
