## 一、接口测试执行登记表结构

| 字段 | 说明 |
|------|------|
| 执行ID | `API-YYYYMMDD-###` |
| 执行日期 | 实际执行日期 |
| 轮次 | 如 API-R1/R2 |
| 请求数 | 本次实际发起请求总数 |
| 通过请求数 | 断言通过（HTTP 200 且 code==0） |
| 失败请求数 | 断言失败 |
| 场景覆盖 | 正常/异常/边界 各自数量 |
| 缺陷ID | 本批次新增接口缺陷（关联 `接口缺陷记录模板.md`） |
| 执行人 | 测试执行人 |
