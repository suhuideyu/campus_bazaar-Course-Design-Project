# 业务报表口径校验报告

> 校验对象：系统 8 份核心业务报表
> 校验方法：**报表口径还原 + 数据库 SQL 重算 + 逐项比对**
> 说明：本报告给出每份报表的**口径定义、还原 SQL、核对步骤**；各报表的实际核对结果（差异与否）以真实执行回填。

---

## 一、校验总体方法

1. **口径还原**：从报表定义还原其统计口径（统计对象、统计时间、过滤条件、聚合维度）。
2. **SQL 重算**：用本报告给出的核对 SQL 在 `campus_bazaar` 库重算报表数据。
3. **逐项比对**：将报表输出与 SQL 重算结果逐行/逐项比对，记录差异。
4. **差异判定**：差异 ≠ 0 即为统计差异，登记差异项并定位根因（口径理解偏差 / 报表 SQL 错误 / 数据源问题）。
