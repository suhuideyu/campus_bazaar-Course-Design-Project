# 数据一致性校验执行说明

> 校验对象：订单、交易（订单-商品状态联动）、库存（商品状态/收藏数）、用户核心数据
> 脚本：`MySQL校验脚本/`（90 条，按 9 个域分组）+ `00_全部校验一键执行.sql`
> 表结构来源：`campus_bazaar.sql`（cb_user / cb_category / cb_item / cb_comment / cb_favorite / cb_order / cb_review）

---

## 一、执行方式

### 方式一：逐域执行

```bash
mysql -uroot -p campus_bazaar < "03_数据校验与报表测试/MySQL校验脚本/05_订单一致性/DB-CK-041_订单号为空.sql"
```

### 方式二：全量一键执行

```bash
mysql -uroot -p campus_bazaar < "03_数据校验与报表测试/MySQL校验脚本/00_全部校验一键执行.sql"
```

## 二、判定标准

| 脚本类型 | 判定标准 |
|----------|----------|
| 违规类校验（DB-CK-001~089） | 返回 **0 行** 表示数据一致；返回任何行即发现疑似异常 |
| 快照校验（DB-CK-090） | 返回 1 行汇总计数，用于与前端/报表数据核对 |

## 三、校验域覆盖

| 域 | 校验数 | 覆盖内容 |
|----|-------:|----------|
| 01_基础数据 | 10 | 分类/用户名唯一性、必填项、密码加密存储 |
| 02_用户一致性 | 10 | 手机号/学校/信用分/角色/状态、外键完整性 |
| 03_商品数据完整性 | 12 | 标题/价格/原价/分类/成色/状态枚举 |
| 04_收藏一致性 | 8 | 唯一约束、fav_count 联动、外键 |
| 05_订单一致性 | 16 | 订单号唯一、买卖双方、价格/卖家三方一致 |
| 06_交易状态一致性 | 12 | 商品状态与订单状态联动、防重复购买 |
| 07_留言一致性 | 6 | 内容长度、外键、回复指向 |
| 08_评价一致性 | 8 | 评分范围、一单一评、评价对象 |
| 09_跨域综合校验 | 8 | 三方一致、外键总检、数据快照 |

## 四、执行日志结构

每次校验执行后，将结果登记到 `数据一致性校验执行日志`（本目录），结构如下：

| 字段 | 说明 |
|------|------|
| 执行日期 | 实际执行日期 |
| 校验范围 | 执行的域 / 脚本编号范围 |
| 异常脚本数 | 返回非 0 行的脚本数 |
| 异常明细 | 脚本编号 + 返回行数 + 摘要 |
| 处理状态 | 登记至异常台账 / 已复核为正常 |
| 执行人 | 测试执行人 |

## 五、常见校验口径说明

1. **价格一致性（DB-CK-050）**：订单成交价应等于商品当前价。系统约定"交易中商品不可改价"，故出现差异即为异常。
2. **状态联动（DB-CK-057~068）**：商品 锁定/已售 必须由订单状态驱动，二者必须同步。
3. **fav_count 联动（DB-CK-036）**：商品收藏计数字段应与 cb_favorite 实际记录数一致，用于校验计数缓存是否失准。
