# 禅道缺陷台账导出格式说明

> 文件：`禅道缺陷台账.csv`
> 用途：禅道（ZenTao）平台缺陷管理台账的**标准导出格式模板**，用于缺陷全生命周期的登记、跟进与统计。
> 说明：当前文件仅含格式示例行（`BUG-001`，已标注【示例行】），正式台账通过禅道「缺陷-导出」功能生成，或以同一字段口径手工维护。

---

## 一、字段口径

| 字段 | 口径说明 |
|------|----------|
| 缺陷ID | 禅道自动编号，如 BUG-001 |
| 所属产品 | 被测产品（本系统：校园二手集市） |
| 所属模块 | 缺陷所在业务模块（用户/商品/分类/订单/留言/评价/管理后台） |
| 严重程度 | 1致命 / 2严重 / 3一般 / 4轻微 |
| 优先级 | P0~P3（P0 最高） |
| Bug类型 | 代码错误 / 界面问题 / 数据问题 / 需求问题 / 建议 / 设计缺陷等 |
| 状态 | 激活 / 已确认 / 已解决 / 已关闭 / 已取消 |
| 标题 | 一句话描述缺陷 |
| 创建人 | 提交人（测试） |
| 指派给 | 处理人（开发） |
| 创建时间 | 提交时间 |
| 解决时间 | 开发解决时间 |
| 解决版本 | 修复所在的版本 |
| 解决方案 | 已修复 / 重复Bug / 不做处理 / 延期处理 / 外部原因 / 设计如此 |
| 已解决 | 0/1 |
| 被激活 | 验证未通过重新激活次数 |
| 激活次数 | 累计激活次数 |
| 由谁关闭 | 验证人（测试） |
| 关闭时间 | 验证通过关闭时间 |
| 复现步骤 | 复现步骤、预期/实际结果（禅道导出为字段或富文本） |
| 关键词 | 检索标签 |

## 二、从禅道导出步骤

1. 禅道 → 测试 → Bug → 缺陷列表；
2. 筛选条件（产品/模块/时间段/严重程度）后点击「导出」；
3. 选择导出字段（勾选上表字段），导出 CSV/Excel；
4. 将导出文件替换/归档到本目录 `禅道缺陷台账.csv`。

## 三、台账与缺陷生命周期的对应

| 生命周期阶段 | 台账字段状态 | 佐证材料 |
|--------------|--------------|----------|
| 提交 | 状态=激活，创建时间 | 复现步骤、截图（见 02_接口测试/接口缺陷记录模板） |
| 跟进/分配 | 指派给、优先级 | 禅道操作记录 |
| 修复 | 状态=已解决、解决方案、解决时间 | 代码提交/版本记录 |
| 验证 | 状态=已关闭、关闭时间、由谁关闭 | 修复验证报告 |
| 重开 | 被激活、激活次数+1 | 验证不通过记录 |

## 四、统计口径

- **高优先级缺陷**：优先级=P0 或严重程度 1/2 的缺陷；
- **闭环缺陷**：状态=已关闭 且 激活次数=0（一次验证通过）的缺陷；
- **全生命周期记录**：提交→跟进→修复→验证→关闭 各环节均有时间与操作记录的缺陷。
