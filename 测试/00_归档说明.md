## 二、材料性质说明

本套归档中，**测试资产类材料均为可运行、可复用的真实工程产物**，基于本仓库真实代码
（控制器层 30+ REST 接口、7 张数据库表、完整业务流程）生成：

| 类别 | 材料 | 性质 |
|------|------|------|
| 测试用例库 | `220条测试用例.csv` | 真实用例设计，可直接投入用例维护与回归执行 |
| 接口集合 | `campus_bazaar.postman_collection.json` | 可直接导入 Postman 运行，覆盖全部接口正常/异常/边界场景 |
| 数据校验 | `MySQL校验脚本/*.sql` | 基于真实表结构的 90 条一致性校验语句，可直接在 MySQL 执行 |
| 自动化 | `Pytest接口自动化/` | 完整可运行框架（50 条接口用例 + 核心流程回归套件） |
| 性能 | `JMeter压测场景/*.jmx` | 5 个压测场景配置，可直接在 JMeter 中加载运行 |

**结果类指标（执行次数、缺陷数量、覆盖率、性能数值、效率提升等）本归档不提供模拟数据。**
对应报告文档均给出度量方法、计算口径与登记规范，实际数值需在真实执行测试后回填，
以保证任何对外呈现的成果指标均有真实执行来源支撑。

## 三、被测系统范围

| 业务模块 | 说明 | 主要接口 |
|----------|------|----------|
| 用户 | 注册/登录/登出/个人信息/收藏列表 | `/api/users/*` |
| 商品 | 列表/详情/发布/编辑/删除/状态流转 | `/api/items/*` |
| 分类 | 分类列表 | `/api/categories` |
| 订单 | 下单/确认/完成/取消/买卖双视角 | `/api/orders/*` |
| 留言 | 留言/嵌套回复 | `/api/comments/*` |
| 评价 | 评价查询/提交/一单一评校验 | `/api/reviews/*` |
| 管理后台 | 用户/商品管理 | `/api/admin/*` |

商品状态机：`0-待审核 → 1-在售 → 2-锁定 → 3-已售`，任意在售状态可 `4-下架`。
订单状态机：`0-待确认 → 1-已确认 → 2-已完成`，任一方可 `3-取消`。
